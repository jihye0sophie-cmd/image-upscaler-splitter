# 이미지 분할 도구 v5.6

브라우저에서 이미지를 1~4 x 1~4로 분할하고, 분할선을 직접 조정한 뒤 개별 이미지 또는 ZIP으로 저장하는 정적 웹앱입니다.

## v5.6 변경사항
- PC/모바일 결과 카드 구조 통일: 이미지 → 파일명 → 해상도 → 저장 버튼
- 개별 `저장` 버튼 클릭 시 저장 방식 선택 시트 표시
  - `파일로 저장`: PC Chrome/Edge 등 지원 브라우저에서는 저장 위치 선택 창 사용
  - `앨범에 저장`: 모바일 Web Share API를 통해 공유 메뉴를 열고 `이미지 저장/사진에 저장` 선택
- 전체 ZIP 저장도 지원 브라우저에서는 저장 위치 선택 창 사용

## 브라우저 제한
일반 웹페이지는 iOS/Android 사진 앨범에 파일을 무단으로 직접 기록할 수 없습니다. 따라서 `앨범에 저장`은 운영체제의 공유 메뉴를 연 뒤 사용자가 `사진에 저장`을 선택하는 방식입니다. iOS Safari/Chrome에서는 `showSaveFilePicker`가 지원되지 않으므로 파일 저장은 브라우저/파일 앱의 기본 저장 흐름을 사용합니다.
