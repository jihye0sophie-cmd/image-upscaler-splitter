# 이미지 분할 도구 v5

GitHub Pages에서 바로 사용할 수 있는 브라우저 기반 이미지 분할 전용 앱입니다.

## 주요 기능
- 가로 1~4, 세로 1~4 자유 분할
- 균등 분할선 자동 생성
- 분할선 마우스/터치 드래그 조정
- 선택한 분할선을 1px 단위로 이동
- 가장자리 여백 제거(px)
- 분할 미리보기
- 개별 이미지 저장
- 전체 ZIP 저장
- PNG/JPG/WEBP 저장
- 서버 업로드 없이 브라우저에서 처리

## GitHub Pages 배포
저장소 최상단에 다음 파일을 업로드하세요.
- index.html
- style.css
- app.js
- README.md

그 다음 GitHub 저장소에서 `Settings → Pages → Deploy from a branch → main / root`를 선택하면 됩니다.

## v5 변경 사항
AI 업스케일 관련 기능과 모델 로딩 코드를 모두 제거했습니다. 이미지 분할 작업에만 집중하도록 앱을 경량화해서 로딩 속도와 반응성을 개선했습니다.


## v5.1
- 분할 결과 미리보기를 선택한 가로 분할 수와 동일한 열 개수로 표시합니다. 예: 4×4는 4개씩 4줄, 3×2는 3개씩 2줄.


## v5.2 변경사항
- 이미지 로드 직후 작업 영역을 먼저 표시한 뒤 분할선을 렌더링하도록 순서를 수정했습니다.
- 최초 로드 시 분할선이 늦게 나타나는 문제를 해결했습니다.
- 화면 크기/패널 크기 변경 시 ResizeObserver로 분할선 위치를 즉시 다시 맞춥니다.
- 가로·세로 분할 수를 바꾸면 분할선이 즉시 다시 생성됩니다.


## v5.3 수정
- 기본 4×4 설정을 건드리지 않고 이미지를 먼저 올려도 분할선이 즉시 표시되도록 초기화 순서를 수정했습니다.
- 브라우저 레이아웃 계산이 늦는 경우 분할선 오버레이를 몇 프레임 동안 자동 재시도합니다.
- 분할 수를 변경하면 기존처럼 즉시 분할선을 다시 생성합니다.


## v5.5 변경사항
- 모바일에서도 개별 저장 버튼이 항상 보이도록 결과 카드 레이아웃 개선
- 각 분할 이미지 아래에 파일명을 표시하고, 그 아래에 저장 버튼을 배치
- 좁은 4×4 결과 그리드에서도 파일명과 저장 버튼이 잘리지 않도록 처리
