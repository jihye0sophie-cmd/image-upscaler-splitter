# 이미지 분할 도구 v5.7

GitHub Pages에서 바로 사용할 수 있는 브라우저 기반 이미지 분할 전용 도구입니다.

## 주요 기능
- 가로 1~4 / 세로 1~4 자유 분할
- 이미지 업로드 직후 기본 분할선 즉시 표시
- 얇은 2px 분할선
- 마우스/터치 드래그로 분할선 이동
- 선택한 분할선 1px 단위 미세 조정
- 분할 미리보기
- 결과 배열을 원본 그리드와 동일하게 표시
- 각 이미지 카드: 이미지 → 파일명 → 해상도 → 저장 버튼
- 개별 파일 저장 / 모바일 앨범 공유 저장
- 전체 이미지 일괄 저장
  - PC Chrome/Edge: 폴더를 한 번 선택하고 모든 이미지를 개별 파일로 저장
  - 모바일: 여러 이미지를 한 번에 공유 메뉴로 전달해 사진 앱 저장 선택 가능
  - 폴더 API 미지원 브라우저: 여러 파일 개별 다운로드 방식 제공
- 전체 ZIP 저장

## 모바일 앨범 저장 참고
웹페이지가 사진 앱에 직접 쓰는 것은 브라우저 보안상 제한됩니다. `앨범에 전체 저장`은 여러 이미지 파일을 한 번에 운영체제 공유 메뉴로 전달합니다. iPhone/iPad에서는 공유 메뉴에서 `이미지 저장` 또는 `사진에 저장`을 선택하면 여러 장을 한 번에 저장할 수 있습니다. 기기/브라우저 버전에 따라 여러 파일 공유를 지원하지 않을 수 있습니다.
