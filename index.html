분할선 미리보기

이미지를 불러오면 분할선이 즉시 표시됩니다. 선을 마우스나 터치로 직접 드래그하세요.

분할 설정

분할 결과

사용 방법

1. 이미지를 올린 뒤 가로·세로 분할 수를 각각 1~4까지 선택합니다.

2. 분할선이 실제 장면 경계와 다르면 선을 직접 드래그하거나 화살표 버튼으로 1px씩 조정합니다.

3. “분할 미리보기 만들기”로 결과를 확인한 뒤 각 이미지 아래의 “저장” 버튼에서 파일 저장 또는 앨범 저장을 선택합니다.

PC Chrome에서는 파일 저장 시 저장 위치 선택 창을 띄웁니다. 모바일의 “앨범에 저장”은 기기 공유 메뉴를 열어 사진 앱 저장을 선택하는 방식입니다.

모든 처리는 서버 업로드 없이 브라우저 안에서 진행됩니다.
